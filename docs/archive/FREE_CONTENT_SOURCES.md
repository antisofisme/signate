## 💾 SUPPORTED FORMATS

### Images
- ✅ JPG/JPEG (recommended for photos)
- ✅ PNG (recommended for graphics with transparency)
- ✅ GIF (animated images)
- ✅ WEBP (modern format, smaller file size)

### Videos
- ✅ MP4 (H.264) - **Most Compatible** ⭐
- ✅ WEBM (VP8/VP9) - Modern web format
- ✅ MOV (QuickTime) - Apple format
- ✅ AVI - Legacy format

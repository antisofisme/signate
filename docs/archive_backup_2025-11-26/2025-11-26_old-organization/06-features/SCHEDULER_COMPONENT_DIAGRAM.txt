├── DeviceSchedule: Device schedule with deadline, countdown
├── DeviceRefreshResult: Single device refresh result
├── BulkRefreshResult: Bulk refresh operation result

║                    COLOR CODING & STATUS INDICATORS                           ║
╚══════════════════════════════════════════════════════════════════════════════╝

Service Status:
  🟢 Green  → Running  (CheckCircle)
  ⚪ Gray   → Stopped  (XCircle)
  🔴 Red    → Error    (AlertCircle)

Device Status:
  🟢 Green  → Online, > 5 min until deadline
  🟠 Orange → Online, < 5 min until deadline
  🔴 Red    → Expired deadline
  ⚪ Gray   → Offline

Icons (Lucide React):
  Clock       → Deadlines, time indicators
  RefreshCw   → Refresh buttons
  CheckCircle → Running, online, success
  XCircle     → Stopped, offline, error
  AlertCircle → Errors, expired deadlines
  Activity    → Service status, activity
  Server      → Devices, empty state
  PlayCircle  → Currently playing

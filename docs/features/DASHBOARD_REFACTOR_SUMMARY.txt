BEFORE (Monolithic Architecture):

ARCHITECTURE LAYERS:
────────────────────────────────────────────────────────────────────────────
  Layer 1: Domain (Pure Business Entities)
    • 12 dataclasses (DashboardStats, DeviceHealthSummary, etc.)
    • No dependencies on frameworks
    • Pure Python objects
    • Immutable

  Layer 2: Repository (Data Access)
    • DashboardRepository with 9 methods
    • All database queries isolated here
    • Organization-scoped filtering
    • Helper methods for common operations

  Layer 3: Use Cases (Business Logic)
    • 9 use case classes
    • Each use case = one business operation
    • Dependency injection (repository)
    • Easy to test with mocks

  Layer 4: Routes (HTTP Handlers)
    • FastAPI endpoints
    • Dependency injection
    • Call use cases
    • Return DTOs
    • NO business logic
    • NO database queries

  AFTER (Clean Architecture):
  ──────────────────────────────
    # Use Case
    class GetDashboardStatsUseCase:
        def execute(self, org_id: int) -> DashboardStats:
            return self.dashboard_repo.get_dashboard_stats(org_id)

    # Route (thin)
    @router.get("/stats")
    def get_stats(user = Depends(get_current_user), 
                  repo = Depends(get_dashboard_repo)):
        use_case = GetDashboardStatsUseCase(repo)
        stats = use_case.execute(user.organization_id)
        return DashboardStatsResponse(**stats.__dict__)

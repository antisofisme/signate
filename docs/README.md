## 🛠️ Maintenance

### Adding New Documentation
1. Determine appropriate category directory
2. Create markdown file with clear title
3. Add entry to category README.md
4. Add cross-references to related docs
5. Update this index if creating new category

### Archiving Old Documentation
1. Move to appropriate archive subdirectory (`/docs/archive/YYYY-MM-DD_topic/`)
2. Update archive README.md with explanation
3. Remove from category README.md
4. Update cross-references

### Documentation Standards
- Use markdown format (`.md`)
- Include "Last updated" date at bottom
- Use relative links for internal references
- Keep README.md in each directory updated
- Follow naming convention: `TITLE_IN_CAPS.md` or `title-with-dashes.md`

│ executed_at │ DATETIME│        │ When device executed            │
│ expires_at  │ DATETIME│ IDX    │ Auto-expire (7 days default)    │
└─────────────┴─────────┴────────┴─────────────────────────────────┘

WORKFLOW:
  1. Admin queues command (status = "pending")
  2. Device polls GET /commands/pending
  3. Device executes command
  4. Device calls POST /commands/{id}/execute
  5. Command status → "executed" OR auto-expire → "expired"

QUERY OPTIMIZATION INDEXES
===========================

devices table indexes:
  ├─ PRIMARY KEY (id)
  ├─ UNIQUE (device_uuid)
  ├─ UNIQUE (unique_code)
  ├─ INDEX (device_type) - Filter by TV/monitor
  ├─ INDEX (status) - Filter by pending/active/inactive
  ├─ INDEX (last_seen) - Find online/offline devices
  ├─ INDEX (organization_id) - Multi-tenant filtering
  └─ INDEX (created_by) - Find devices by creator

device_tags indexes:
  ├─ PRIMARY KEY (device_id, tag_id)
  └─ INDEX (tag_id) - Find all devices with tag

device_commands indexes:
  ├─ PRIMARY KEY (id)
  ├─ FOREIGN KEY INDEX (device_id) - Find commands for device
  ├─ INDEX (status) - Find pending/expired commands
  └─ INDEX (expires_at) - Find expired commands

device_speed_tests indexes:
  ├─ PRIMARY KEY (id)
  ├─ INDEX (device_id) - Find test history for device
  ├─ INDEX (tested_at) - Find tests in time range
  └─ INDEX (quality) - Analyze connection quality


DISK SPACE ESTIMATIONS
=======================
(Per 1000 devices, assuming MySQL InnoDB)

devices              ~  500 KB
device_tags          ~  100 KB (avg 3 tags per device)
device_logs          ~  5-10 MB (1KB per log, assuming moderate usage)
device_commands      ~  200 KB (avg 5 commands, 7-day retention)
device_speed_tests   ~  500 KB (100 tests per device)
playlist_assignments ~  100 KB (avg 2 playlists per device)
content_assignments  ~  200 KB (avg 5 content items per device)

TOTAL: ~7-17 MB per 1000 devices (grows with logging volume)


COMMON QUERIES
==============

Find online devices:
  SELECT * FROM devices 
  WHERE status = 'active' 
  AND last_seen > NOW() - INTERVAL 5 MINUTE;

Find devices by tag:
  SELECT d.* FROM devices d
  JOIN device_tags dt ON d.id = dt.device_id
  WHERE dt.tag_id = ?;

Find content assigned to device (including tags/playlists):
  SELECT c.* FROM contents c
  JOIN content_assignments ca ON c.id = ca.content_id
  WHERE (ca.device_id = ? OR ca.tag_id IN (
    SELECT tag_id FROM device_tags WHERE device_id = ?
  ))
  AND ca.is_active = true
  ORDER BY ca.priority DESC, ca.display_order ASC;

Find pending commands for device:
  SELECT * FROM device_commands
  WHERE device_id = ?
  AND status = 'pending'
  AND expires_at > NOW()
  ORDER BY created_at ASC;

Count devices by status:
  SELECT status, COUNT(*) as count
  FROM devices
  WHERE organization_id = ?
  GROUP BY status;

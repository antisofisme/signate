╔═══════════════════════════════════════════════════════════════════════════╗
║ TASK LIFECYCLE                                                            ║
╚═══════════════════════════════════════════════════════════════════════════╝

1. UPLOAD REQUEST
   ├─ POST /api/content/upload?transcode=true
   ├─ Create TranscodingTask (PENDING)
   ├─ Queue Celery task to Redis
   └─ Response: 202 Accepted {task_id: 1}
   
2. BACKGROUND PROCESSING
   ├─ Worker dequeues from Redis
   ├─ Set status = PROCESSING
   ├─ Update Redis progress = 0%
   ├─ Run FFmpeg with progress tracking
   │  └─ Update Redis every 10%
   ├─ On success:
   │  ├─ Upload result
   │  ├─ Set status = COMPLETED
   │  └─ Set progress = 100%
   └─ On failure:
      ├─ Retry attempt 1 (after 5s)
      ├─ Retry attempt 2 (after 10s)
      ├─ Retry attempt 3 (after 20s)
      └─ Mark FAILED if all fail

3. PROGRESS POLLING
   ├─ GET /api/tasks/{task_id}
   ├─ Query DB for task status
   ├─ Query Redis for progress
   └─ Return {status, progress, eta}

4. COMPLETION
   ├─ status = COMPLETED
   ├─ progress = 100%
   └─ content_id available for use

╔═══════════════════════════════════════════════════════════════════════════╗
║ API ENDPOINTS                                                             ║
╚═══════════════════════════════════════════════════════════════════════════╝

1. UPLOAD WITH TRANSCODING
   POST /api/content/upload
   
   Request:
   {
     file: <binary>,
     title: "My Video",
     transcode: true,
     target_format: "h264",
     target_resolution: "1920x1080",
     target_bitrate: 5000
   }
   
   Response: 202 Accepted
   {
     "task_id": 1,
     "message": "Video queued for transcoding"
   }

2. GET TASK STATUS
   GET /api/tasks/1
   
   Response: 200 OK
   {
     "task_id": 1,
     "status": "processing",
     "progress": 45,
     "message": "Transcoding... 45%",
     "eta_seconds": 120,
     "content_id": null,
     "error": null
   }

3. LIST ACTIVE TASKS
   GET /api/tasks/active
   
   Response: 200 OK
   {
     "active_count": 2,
     "tasks": [
       {"task_id": 1, "status": "processing", "progress": 45},
       {"task_id": 2, "status": "pending", "progress": 0}
     ]
   }

4. CANCEL TASK
   DELETE /api/tasks/1
   
   Response: 204 No Content

✓ ASYNC PROCESSING
  Video upload returns immediately (202 Accepted)
  Transcoding happens in background
  Non-blocking for API

✓ PROGRESS TRACKING
  Real-time 0-100% progress
  Via Redis (fast in-memory)
  Updated every 10% of transcoding
  ETA time remaining

✓ AUTOMATIC RETRIES
  3 automatic retry attempts
  Exponential backoff (5s → 10s → 20s → 80s)
  Survives worker restart
  Detailed retry history

✓ JOB PERSISTENCE
  PostgreSQL: Source of truth
  Redis: Fast progress lookup
  Celery: Task metadata
  Survives server restart

✓ STATUS TRACKING
  pending → processing → completed/failed
  Stored in database
  Updated in real-time
  Accessible via API

✓ ERROR HANDLING
  Detailed error messages
  Error codes for categorization
  Automatic logging
  Graceful degradation

✓ MONITORING

✓ SCALABILITY

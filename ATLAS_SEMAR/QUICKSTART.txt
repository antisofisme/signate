🆘 TROUBLESHOOTING:

❌ "pip3 command not found"
   → Use "pip" instead: pip install -r requirements.txt
   → Or install Python 3 from python.org

❌ "ModuleNotFoundError: pynput"
   → Reinstall: pip3 install -r requirements.txt

❌ "F12 hotkey not detected"
   → Make sure JARVIS window is focused
   → Try running as admin (sudo python3 -m jarvis.main)
   → Or change hotkey in the code

❌ "No audio device found"
   → Check microphone is connected
   → Check system audio settings

❌ "STT timeout (slow transcription)"
   → Increase timeout or use faster model
   → See INSTALLATION_GUIDE.md for custom settings

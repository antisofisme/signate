## 🚀 HOW TO INSTALL ON YOUR MACHINE

### **For Windows Users:**

1. **Download the code**
   - Download all files from `/mnt/f/WINDSURF/neliti_code/signate/SEMAR/`
   
2. **Open Command Prompt or PowerShell**
   ```bash
   cd C:\Users\YourName\Downloads\SEMAR
   ```

3. **Install Python** (if not installed)
   - Download from https://www.python.org/downloads/
   - Choose Python 3.9 or higher

4. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

5. **Run JARVIS**
   ```bash
   python -m jarvis.main
   ```

### **For Mac Users:**

```bash
# Navigate to project
cd /path/to/SEMAR

# Install dependencies
pip3 install -r requirements.txt

# Run JARVIS
python3 -m jarvis.main
```

### **For Linux Users:**

```bash
# Navigate to project
cd /path/to/SEMAR

# Install dependencies
pip3 install -r requirements.txt

# Or with sudo (if needed)
sudo pip3 install -r requirements.txt

# Run JARVIS
python3 -m jarvis.main
```

## 🆘 NEED HELP?

### If pip is not found:
```bash
# Try pip3
pip3 install -r requirements.txt

# If that fails, install pip first
python3 -m ensurepip
pip3 install -r requirements.txt
```

### If you get "No module named 'pynput'"
```bash
# Manually install each package
pip3 install pynput
pip3 install sounddevice
pip3 install openai-whisper
pip3 install numpy
pip3 install pytest
```

### If you get "Hotkey not detected"
- Make sure JARVIS window is focused
- Try running as administrator
- Or change hotkey in code

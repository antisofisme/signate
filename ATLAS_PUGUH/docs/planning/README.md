## Guidelines

1. **Prefix with date**: Use `YYYY-MM-DD-` prefix for time-sensitive documents
2. **Mark status clearly**: DRAFT, IN PROGRESS, APPROVED, ARCHIVED
3. **Link to specs**: Reference Layer 0-3 documents when applicable
4. **Archive when done**: Move completed planning docs to `archive/` subdirectory

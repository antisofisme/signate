# Smart TV Signage Implementation Skill

## Cara Pakai Skill Ini

### 1. Invoke Skill

Ketik slash command:
```
/smart-tv-signage-implementation
```

Atau panggil skill via prompt:
```
@smart-tv-signage-implementation mulai implementasi dari Phase 1
```

### 2. Skill Akan Guide Step-by-Step

Skill akan:
- ✅ Guide implementasi dengan urutan yang benar
- ✅ Validasi setiap step sebelum lanjut
- ✅ Mencegah skip steps yang penting
- ✅ Memberikan checklist validation
- ✅ Warning jika ada yang salah

### 3. Ikuti Phase Secara Berurutan

**JANGAN skip phase!**

```
Phase 1: Foundation (Database + Backend Core)
  ↓
Phase 2: Backend Features (Device, Content, Anthias)
  ↓
Phase 3: Docker Compose
  ↓
Phase 4: Web Admin UI
  ↓
Phase 5: Monitor Viewer
  ↓
Phase 6: WebOS TV App
```

### 4. Complete Validation Checklist

Setiap step punya **Validation Checklist**.

**HARUS** complete semua checklist sebelum lanjut!

Contoh:
```
Step 1.1: Database Schema
Validation Checklist:
- [ ] All tables created
- [ ] Foreign keys defined
- [ ] Indexes added
- [ ] Seed data exists
- [ ] Can connect to PostgreSQL
```

### 5. Test Sebelum Lanjut

Setiap step ada **Test Command** untuk validasi.

Jalankan test command untuk memastikan step benar.

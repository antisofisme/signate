NOTES
================================================================

- device_commands.completed does NOT exist in current schema
  The table uses status VARCHAR('pending'|'sent'|'executed'|'failed')
  instead of a boolean completed field. This was mentioned in the
  master plan but is not applicable to current schema.

- The migration includes verification queries to ensure all boolean
  columns follow the is_* naming convention.

- Some exceptions are acceptable (e.g., 'active', 'deleted', 'read')
  as they are well-understood status fields.

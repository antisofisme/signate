# MANTRA Layer 1: Implementation Specifications

**TYPE**: Specification Repository
**STATUS**: FROZEN (per MANTRA-L1-FREEZE-001)
**AUTHORITY**: Human Decision Only
**GOVERNING LAW**: MANTRA-LAW-001

---

## Notice

Layer 1 contains implementation specifications.

Layer 1 does NOT contain law, binding decisions, or authority grants.

Layer 1 is subordinate to Layer 0 in all cases.

---

## Boundary Constraint

All Layer 1 documents are governed by:

**MANTRA-LAYER-1-BOUNDARY-001** (Implementation Boundary Rules)

This boundary specification prevents Layer 1 from violating Layer 0.

## Layer 0 Supremacy

Layer 0 is constitutionally superior.

Layer 1 implements. Layer 1 does not redefine.

If conflict exists between Layer 1 and Layer 0:

**Layer 0 prevails. Layer 1 is corrected or discarded.**

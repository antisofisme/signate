### 1.3 User Flows

#### 1.3.1 Tenant Onboarding Flow

```
┌─────────────────────────────────────────────────────────────────────────┐
│                       TENANT ONBOARDING FLOW                            │
└─────────────────────────────────────────────────────────────────────────┘

┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌────────┐
│ Create   │───►│ Start    │───►│ Setup    │───►│ Add      │───►│ Active │
│ Tenant   │    │ Trial    │    │ Org      │    │ Subs     │    │        │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └────────┘
     │               │               │               │               │
     ▼               ▼               ▼               ▼               ▼
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌────────┐
│ Fill     │   │ Set      │   │ Create   │   │ Select   │   │ Send   │
│ Basic    │   │ Trial    │   │ First    │   │ Apps &   │   │ Welcome│
│ Info     │   │ Duration │   │ Org      │   │ Tiers    │   │ Email  │
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └────────┘

Status Changes:
pending → trial → active

Timeline:
Day 0: Create tenant, start trial
Day 1-14: Trial period (configurable)
Day 14: Convert to active OR extend trial OR suspend
```

```
┌─────────────────────────────────────────────────────────────────────────┐

└──────────┘    └──────────┘    └──────────┘    └──────────┘    └────────┘
     │               │               │               │               │
     ▼               ▼               ▼               ▼               ▼
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌────────┐
│ Dec 1-31 │   │ - Subs   │   │ Edit if  │   │ Email to │   │ Record │

└──────────┘   └──────────┘   └──────────┘   └──────────┘   └────────┘

Status Flow:
draft → sent → paid
             → overdue → paid
             → cancelled
```

## Part 5: Accessibility (A11y)

### 5.1 Requirements

- WCAG 2.1 Level AA compliance
- Keyboard navigation for all interactions
- Screen reader support (ARIA labels)
- Color contrast ratio minimum 4.5:1
- Focus indicators visible
- Form error announcements
- Skip to main content link

### 5.2 Focus Order

```
1. Skip link (hidden until focused)
2. Header (logo, search, profile)
3. Sidebar navigation
4. Page header (title, actions)
5. Main content
6. Footer (if exists)
```
